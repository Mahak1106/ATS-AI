# ATS.AI - Smart Recruitment Platform

ATS.AI is a Flask-based Applicant Tracking System designed to streamline the recruitment process for recruiters and candidates.

## Features

* User Authentication (Recruiter & Candidate)
* Job Posting & Management
* Job Search & Applications
* Resume Upload & Download
* AI Resume Ranking
* Candidate Shortlisting
* Interview Scheduling
* Recruitment Analytics Dashboard
* Email Notifications

## Tech Stack

* Python
* Flask
* SQLite
* HTML
* CSS
* Bootstrap
* Chart.js

## Project Structure

* app.py
* database.py
* templates/
* static/
* uploads/
